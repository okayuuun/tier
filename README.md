# なかみくらべ。v11 — カスタム問題作成の拡張

## 追加した内容

- アトリエで問題セットを好きな数だけ作成：Tier表 1〜15お題、ウミガメのスープ 1〜20問、理解度・二択・価値観 1〜30問。
- お題・問題の複製、並べ替え、削除、切り替え。
- 問題文・Tier候補・選択肢に写真を追加。PNG/JPEG/WebPを画面内で縮小（長辺最大320px）してブラウザに保存。HTTPSの画像直接URLも入力可能。
- ソロプレイは1問ずつ表示し、回答後に全問の採点または真相を確認。昔の問題データを読める互換処理。
- 元ネタの名称が分かる表記に変更（ゲーム内容自体はそのまま）。これは各商用ゲームの公式サイトではありません。
- 画像の少ない問題は従来通りURL内にデータを保持。長い問題は `/api/challenges` に一時保存し、短いURLで共有。
- バックアップJSONは画像込みで保存・復元できます。保存数・ブラウザ容量には上限があります。

## 注意

- アトリエの保存先は**各自の端末・ブラウザの localStorage**。端末を変えても自動同期されません。
- 長い問題用の**短い共有リンク**はサーバーのメモリに最大36時間保存します。Render再起動時は期限内でも消えます。問題を確実に残すには**JSONバックアップ**を使ってください。
- 共有データには出題者の正解も含まれるため、リンクを解析すれば見ることができます。ソロ用の厳格な不正防止には向きません。
- 既存のリアルタイムゲームは変更していません。アトリエで作った多数問セットを直接リアルタイムルームに持ち込む機能は別途実装が必要です。
- 画像の利用には、持ち主や撮影者の許可、公開先の条件を確認してください。提示された文章を勝手に言い換えることは避け、未提供の市販カード・問題集の全文は収録していません。

## 第12版：アトリエの問題をリアルタイムで出題（2026-11-08）

アトリエ `/studio` で作成・保存した問題を、メインのルーム `/` に持ち込めます。

1. アトリエの「保存したゲーム」から **👥 みんなで遊ぶ** を選択（またはメイン画面でルーム作成後に保存済みゲームを選択）。
2. ホストがゲームを読み込みます。別ブラウザで作った問題は **JSONバックアップ** から読み込みます。
3. 友達がルームコードで参加したら開始します。作者が出題者で、他の全員が回答します。
4. Tier表はお題ごとにS〜Dを予想、クイズ・二択・価値観は1問ずつ回答、ウミガメのスープは出題者に質問します。
5. 参加者全員の結果・得点・最終ランキングを確認できます。

### 対応する形式

- Tier表：最大15お題、5候補の順位と各候補の画像
- 理解度クイズ：最大30問、4択、画像付き
- 恋愛究極の２択：最大30問、2択、画像付き
- これって重い？判定シート：最大30問、3択、画像付き
- ウミガメのスープ：最大20問、出題者専用の真相、3段階ヒント、画像付き

**正解の扱い：** ホストのブラウザからサーバーに送る際は問題セットと正解が含まれますが、参加者向けの画面には答え合わせ前の正解は送られません。サーバー保存はメモリ上だけで、Render再起動で消えます。

**制限：** ルームに読み込む1セットは最大650KB。自動で縮小された画像でも、枚数が多い場合は分割してご利用ください。全員の回答は試合中のルームメモリに保持され、ログイン・永続データベースへの同期はありません。現時点ではホストが問題を持ち込む形式で、別の人がそれぞれ独立した問題を同じ試合で追加する仕組みはありません。

起動方法は従来と同じです。`pip install -r live/requirements.txt` を実行し、`python live/server.py` で開始します。Renderでは **Deploy latest commit** を選んで更新します。


## マスター管理 v13（サイト運営者向け）

ゲーム一覧やアトリエ画面の下部にある小さな「···」を押すか、PCで `Ctrl + Shift + K` を押し、コマンド `okayu` を入力します。これは**入口を表示するための合言葉**であり、管理認証ではありません。開いた管理画面ではマスターパスワードでログインしてください。

**必須設定**：Render の `tier` サービス → **Environment** → `MASTER_PASSWORD` を追加し、他人に知られていない12文字以上の強いパスワードを登録してください。`okayu` をパスワードにはしないでください。設定後は Render で再デプロイします。

管理ページ：`/master`。全10ゲームの公開・非公開切り替え、現在のルーム表示・強制終了、ニックネーム・日時・ゲーム・操作名のログ検索／削除、ラウンドや得点の履歴・削除、全管理データのJSON書き出しができます。画面にはゲームの答え合わせ済みの内容を表示します。公開オフになったゲームは新規選択・開始できず、ソロの一時共有APIでも取得できません。すでに開始中のルームはそのまま継続します。

**安全性・プライバシー**：ユーザーが入力する `okayu` だけでは管理できません。操作にはサーバー側パスワード認証によるHttpOnlyクッキーが必要で、管理APIは同一サイトからの操作以外を拒否します。参加者には操作ログを記録する旨がサイトの参加画面で通知されます。操作ログはニックネーム・時刻・ルーム・ゲーム・操作種別と設定ゲーム名のみ記録し、個別の秘密の回答・発言本文・IP・セッションIDを操作ログに保存しません。対戦履歴には公開済みのラウンド結果・得点を保存します。端末ごとのブラウザ内に保存した未共有データは、管理者も閲覧・削除できません。

**保存の制限**：初期値はSQLiteで、`MASTER_DB_PATH=/tmp/nakami_master.sqlite3` に保存します。Render無料プランではファイルは永続ではなく、サービスの再作成・再デプロイ・再起動などで公開設定も含めて失われる可能性があります。永続保存には外部DBか永続ディスクを導入してください。永続ディスクを使う場合は `MASTER_DB_PATH` をそのマウント下（例：`/var/data/nakami-master.sqlite3`）へ変更できます。記録は操作ログ30日／最大5000件、ゲーム履歴90日です。JSONを書き出してバックアップしてください。ログの取得と削除は管理者だけが可能です。

**注意**：このリポジトリをPublicにしている以上、ブラウザ配信コード自体は誰でも参照できます。非公開はサイト内でゲーム選択・プレイを止める機能であり、作品のソースコードを完全に秘匿する仕組みではありません。


## 第14版：リアルタイムゲームを3種類追加

従来の10ゲームに加え、合計 **13ゲーム** を選べます。

- **全員一致ゲーム（2〜12人）**：全員同じお題に自由回答。8ラウンド以内に5回一致を目指します。オリジナルのお題52個。
- **インサイダーゲーム（4〜12人）**：親だけでなく秘密の内通者も正解を知る状態で質問・推理・正体投票。順番に親を交代します。公式作品とは配点・制限時間等が異なる独自Web版です。
- **シークレットランキング（3〜12人）**：主役は秘密の基準で5項目をS〜Dに並べます。残りの全員は並びを見て4つの候補から基準を推理します。既存Tier予想とは別ゲームです。

3ゲームともブラウザからリアルタイム参加、スマホ操作、図解ルールスライド、最終履歴、マスター画面での公開・非公開設定および操作ログに対応しています。ゲームの進行処理は `live/party_extra.py`、例題は `live/party_extra_data.py` にあります。

**本番への反映方法:** Render の `tier` サービスを選択し `Manual Deploy → Deploy latest commit`。最新のコミットがデプロイされる前のサイトは旧バージョンです。マスター管理のパスワードは `MASTER_PASSWORD` の環境変数で設定します。サーバー再起動後の永続保存には別途DBが必要です。



## 第15版：追加3ゲーム＋操作フィードバック（2026-11-09）

ゲームは合計16種類（既存13＋以下の3種類）。既存のルーム・アトリエの遊び方は維持しています。

- **エセ芸術家ニューヨークへ行く（Webアレンジ）**：5〜12人。32個の独自お題と共通SVGキャンバスを使い、1人だけ知らないお題をみんなで描き、投票で当てます。疑われたエセ役には逆転チャンスがあります。公式作品そのものではありません。
- **謎解きメール**：2〜12人。5つのオリジナル事件、それぞれ3段階（計15ステップ）の協力謎解き。架空メールの複数の手掛かりを読み解き、正解したプレイヤーに得点。主催者はヒントを公開できます。

### 押した反応と進行表示

- ボタンを押したときの拡縮反応・選択ハイライト、正解／結果公開時の控えめなアニメーション。
- Web Audio APIで生成するオリジナルの短い効果音。ページ上部の「効果音 ON/OFF」で切替。設定は各ブラウザに保存し、利用環境の自動再生制限に従います。
- ゲーム中の現在の進行（待機・出題・回答・投票・結果など）を色と文字で表示。音なし・動きを抑えるOS設定でも利用できます。
- マスター管理画面で新ゲームの公開／非公開を切替可能。操作履歴・結果も登録。Render無料サーバー再起動時の記録消失には引き続き注意してください。

開発時には `python live/test_more_modes.py` で新しい3ゲームのラウンド、秘密情報、得点、権限チェックを実行できます。CIではPython全ファイルの構文、JS全ファイルの構文、既存モード＋新モードのスモークテストを実行します。


## 第16版：昼ドラ川柳・57577・横暴編集長（非公式Webアレンジ）

新しく3つのリアルタイムゲームを追加。マスター管理画面で個別に公開・非公開を設定できます。

- **昼ドラ川柳**：2〜12人。ホストが5・7・5、5・7・5・7・7、5・5・7・7、7・7・7・5、または2〜6句の自由な5/7構成を選択。親以外が句を作り、作者を伏せて親がベスト作品を選びます。選ばれた人は1点。親を交代します。
- **５７５７７（ゴーシチゴーシチシチ）**：2〜12人。基本は5・7・5・7・7。自由な型を選択可能。全員が作品を提出し、作者を伏せて自分以外の作品に投票。最多票の作者に2点（同票は双方）。
- **横暴編集長**：3〜12人。上の言葉と下の言葉を1つずつ組み合わせ、面白いタイトルを作ります。提出した作品に匿名投票し、最多票の作者に2点。自分には投票できません。

### 標準デッキとカスタムデッキ
- 5音80語・7音75語、タイトル前半60語・後半60語の**独自**デッキを収録。
- 標準は手札からタップして選ぶだけ。各行への自由入力にも対応。音数は厳密には強制しません。
- ホストはルーム待機画面の「マイカードを登録して遊ぶ」を開き、各種類に2〜200語を改行区切りで入力できます。入力デッキは本人のブラウザに保存され、その部屋へ送信して使います。公開リポジトリにはアップロードされません。
- マスター管理では senryu, tanka, booktitle をそれぞれ公開/非公開にできます。操作とゲーム結果は管理履歴の対象です（サーバー再起動時の永続性には別途データベースが必要）。
