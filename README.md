# なかみくらべ。v9 — リアルタイム版

ルームを作り、友達と同じURLからスマホ/PCで遊ぶパーティーサイト。既存の7ゲームを維持し、「アカイイト」（数値ペア探し）と「全員不一致チャレンジ」を追加しました。

## 今回追加した遊び

### ❤️ アカイイト｜100になるペア（2〜10人）

- 各自に1〜100の数字を秘密で1つ配ります。全員がテーマに沿って言葉で表現します（数字の記入は禁止）。
- 言葉から合計が100に近そうな相手を探し、ペアを申請。相手は承認・拒否できます。
- 成立すると数字を公開。**100を超えると0点**、100以下は合計に応じて1〜5点、**100ぴったりは6点**。4ラウンドの総合得点を競います。
- これはArclight社『ito』の「アカイイト」に着想を得た**Web向け独自の採点・承認方式**です。公式ゲームと得点・細部は一致しません。公式のテーマカードやデザイン・素材は使用していません。
- 公式説明：https://arclightgames.jp/product/ito/

### ✨ 全員不一致チャレンジ（2〜12人）

- 全員が同じお題を見て、一度にそれぞれ好きな回答を提出します。
- 誰とも被らなければ成功。誰かと同じなら失敗し連続記録は0へ戻ります。
- 10問以内に5回連続成功すれば協力勝利。オリジナルのお題70個からランダム出題します。
- レトルト/キヨ/牛沢/ガッチマンの「全員不一致ゲーム」実況を参考にした独自ルールです。
- 参考動画：https://www.youtube.com/watch?v=M1XPFzGB4RA

### 🔎 ウミガメのスープ改修

- 旧問題を見直して **26問の独自問題**に差し替えました。すべてに「問題文・真相・3段階ヒント・出題者の確認ポイント・想定Q&A」を用意。
- 出題者画面にガイドを折りたたみ表示。真相とガイドは出題者以外に送信しません。
- 問題開始前に引き直し可能。★4以上の難問を優先するボタンも追加しました。
- 実際の高評価問題を無断転載せず、出題者だけに元の問題集リンクを掲載します。外部サイトの利用規約と権利を確認してください。
- 参考: https://www.umigame-quiz.com/collections/high-rated-umigame , https://sui-hei.net/mondai , https://quizmondai.com/lateral-thinking/

## ローカル起動（Windows）

```powershell
py -m pip install -r live/requirements.txt
py live/server.py
```

`http://localhost:8080/` をブラウザで開く。

## Renderで公開する

GitHubの最新コミットをデプロイしてください。
- Build Command: `pip install -r live/requirements.txt`
- Start Command: `python live/server.py`
- Health check: `/health`

Render の無料サービスはアクセスがないと停止し、復帰に時間がかかることがあります。再起動でルームと進行状況は消えます。

## v10 — 自分のアトリエ、プロフィール保存、ソロ出題

- `/studio` に **作問アトリエ**を追加。Tier/二択/価値観/理解度クイズ/ウミガメのスープを作成・編集。
- **プロフィール**の名前・絵文字・写真（JPEGへ96×96に縮小）と自作ゲーム、直近のプレイ結果を `localStorage` に保存。ブラウザ・端末を変えると同期されません。
- **出題リンク**は `https://ホスト/studio#play=...` 形式。リンクのみで解答可能。クイズとTierは自動採点、スープはヒントと真相を段階的に開示します。
- **注意：**出題リンクには問題と正解の情報が含まれます。正解の秘匿・不正防止・結果回収・成績管理を保証するサービスではありません。採点結果は回答者側に保存され、作者へ自動送信されません。
- **バックアップ**: アトリエの保存一覧からJSONを書き出し／読み込み。削除やブラウザのストレージ消去で消えることがあります。
- リアルタイム版では自分の作ったTier・二択・価値観・理解度クイズを読み込み、本人が正解を改めて登録できます。
- ウミガメのスープは出題者が質問開始前に保存済みの自作問題に切り替え可能。出題者以外への真相漏洩が起きないよう送信内容を分離しています。
- ウミガメのスープの出題者画面に、高評価作品の**掲載元へのリンク**を追加。サイトや市販問題の全文を無断転載していません。
- `アカイイト`と`全員不一致`はv9から収録。公式作品の完全なデジタル移植ではなく、本サイト独自の簡易採点・進行です。
