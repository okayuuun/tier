# 2026-11-09 追加：絵チャの🪣バケツ（領域塗りつぶし）

- `/echa` に **「🪣 バケツ」** を追加しました。クリック／タップした場所から、連結している同系色の範囲を塗ります。塗りつぶし範囲の探索は上下左右につながるピクセルを使い、境界線の外には広がらない仕組みです。
- 色は既存のカラーピッカーから選べます。既存の「透明度」スライダーも塗りつぶしに反映します。
- **色の許容値（0〜100）**：小さいほど近い色だけ、大きいほど差がある色にも塗りが広がります（既定15）。
- **選択中のレイヤーのみ参照**：そのレイヤーの色・線だけを塗り範囲の境界にします。
- **表示中の全レイヤーを参照**：ほかの表示中レイヤーの線・色も塗りの境界に使い、変更するのは**選択したレイヤーだけ**です。線画を上、色用レイヤーを下にして線画を保護しながら塗れます。
- バケツのクリックはWebSocketで全員に同期し、通常の描画履歴と同じように「自分の線を戻す」、後から参加した人への再描画、全体PNG保存、タイムラプスへ反映します。
- **塗りつぶしは描画を描かれた順番に再計算します**。レイヤーの順序・表示状態・過去の線を変更すると、境界を再計算して結果が変化する場合があります。
- キャンバスサイズは3072×2048pxのままです。塗る範囲がとても広いと、スマホなどで処理に少し時間がかかる場合があります。線に隙間がある場合は塗りが外まで広がるため、失敗したら「自分の線を戻す」を押してください。
- 過剰な処理を防ぐため、塗りつぶしは部屋あたり最大120回、同じ参加者の操作間隔を0.65秒以上に制限しています。
- 描画内容の保存は従来同様サーバーメモリのみです。再起動で失われることがあるため、大切な作品はPNG／WebMで保存してください。

**簡単な手順**：`線画（上のレイヤー）を描く → 下に新しい色用レイヤーを置く／選択 → 🪣バケツ → 「表示中の全レイヤーを参照」 → カラーピッカーから色選択 → 領域内をタップ`。

自動テスト：`python live/test_echa.py`（WebSocket同期・不正パラメータ・取り消し）、`node live/test_echa_fill.js`（囲み・許容値・透明度）、`node live/test_echa_bucket_render.js`（線画と色が別レイヤーの塗り分け）。

## 🗂️ 絵チャ共有レイヤー

## 🎭 誰のエピソード？（ルーム内で選択）

- 3〜12人で遊べます。既存のルーム作成 → ゲーム一覧から「誰のエピソード？」を選択 → 開始。
- 全3ラウンド。主催者がお題を自由入力または20個の例題から選択。
- 全員が8〜320文字で匿名投稿。全員分（もしくは主催者が3件以上で先に進める場合）が集まるまで文章を他人に公開しません。
- 匿名表示後に、各文章の書き手を全員1人ずつ予想します。自分のエピソードは判別済みで、推理から除外。
- 正解すると2点、ほかの人が作者を間違えたとき、そのエピソードの作者に1点。回答済みの予想はまとめて答え合わせ。最後に順位を表示。
- **プライバシー**：書いたエピソードは対戦参加者に最終的に公開されます。実話でも創作でも遊べます。個人情報や他人の秘密は書かないでください。

## 🌈 プロフィール工房（`/profile-maker`）

- 好きな色や模様、フォント、1列／2列、カバー・アバター画像を設定。
- 11種類のカード（文章、基本情報、タグ、リスト、ランキング、質問と回答、年表、リンク、画像、引用、区切り）を最大30枚まで追加・並べ替え・複製・非表示にできます。
- 5つのテーマプリセットとカラーピッカー。変更はリアルタイムにプレビューへ反映されます。
- ログイン不要・ブラウザ内に自動保存。JSONの書き出し／読み込み、印刷・PDF保存が可能。
- 「共有リンクをコピー」は **プロフィール全文をURLのフラグメントに埋め込みます**。大きな写真はリンク制限のため、画像URLにするかJSONを共有してください。閲覧相手の画面には編集前の自分の保存データは流れません。
- プロフィール内容はURLを知る人に見えます。公開前に住所・学校・連絡先などの情報がないか確認してください。Google検索などに保存されないことは保証されません。

## 🎨 みんなの絵チャ（`/echa`）

- 新しい絵チャの部屋を作り、招待リンクで友達を呼びます。最大12人が同じ **3072×2048px** のキャンバスで同時に描けます。
- ペン・消しゴム・色・透明度・線幅、拡大縮小・移動を利用できます。描画中の線も徐々に共有されます。
- 参加者表示、リアルタイムの文字チャット、描いた本人による線の取り消し、部屋作成者による全消去・再接続。

- **タイムラプス**：完成した線を描画順に再生。再生速度切り替え、再生位置の操作、対応ブラウザでWebM動画として保存。消した線は最終的な画像に含まれません。
- スマホの場合はペンと「✋ 移動」モードを切り替えて操作。PCはホイール拡大縮小、Spaceキー＋ドラッグでも移動できます。
- **保存上の注意**：絵チャの共同編集状態はサーバーのメモリに保存します。Renderの再起動・再デプロイで **絵・チャット・ルームが消える可能性**があります。大切な絵はPNGまたはタイムラプスで定期的に保存してください。外部データベースは接続していません。

# 2026-11-09 強化版：ミリしら答え合わせ・展示会／お絵描き便利ツール

### キャラクター・ミリしら（`/milli`）
- 出題者は画像・質問（自由記述／選択式）・**本当の答え（質問ごと）**・**公式設定メモ（キャラごと）**を入力できます。公式設定の入力は任意で、**回答中の公開APIからは完全に除外**します。
- **作品名を伏せる**機能と、登録キャラから**指定人数をランダム出題**する機能を追加。ランダム出題されたキャラだけで回答を提出できます。
- 回答者は最後に「ニックネームと回答を展示会で公開してもよい」に明示的に同意できます。**初期状態は同意なし**です。作者専用の結果画面には同意に関係なく回答が表示されます。
- 作者専用結果画面でキャラ別の**公式設定と全員の回答比較**、CSV/JSON出力、公開展示会のON/OFFができます。
- **展示会URL**（`/milli#gallery:<id>`）は、作者がONにしたときだけ有効。公式設定と**同意済み回答のみ**を公開します。掲載不同意の回答は他人には見えません。
- 回答送信後、そのブラウザには投票用のランダムトークンを保存します。展示会では回答者ごとに1票、投票先変更可、**自分への投票不可**。トークンを持たない閲覧者は投票できません。
- **重要**：リンクを公開しただけでは作者の答えを含むデータは回答者に送られません。ただし、作者が展示会を公開した後はネタバレになります。全員の回答終了後の公開をおすすめします。

### お絵描き
- 既存のパーティーお絵描き画面（伝言・合作・デザイン等）に**ペン／線消しゴム／スポイト／PNG保存**を追加。
- 線消しゴムは触れた線を1本削除する方式で、ピクセル単位の部分消去ではありません。
- 既存の最大6レイヤー、レイヤーごとの透明度、色選択に加えて**レイヤー前面・背面への移動**と**好きな色12色の保存**を追加。
- 色パレットは同じブラウザの複数のお絵描きゲームで共通利用。PNGは画面に表示された絵を保存します。

### 保存上の注意
- 出題者のセット草稿・保存したパレットはブラウザの `localStorage` に保存。別端末には自動同期されません。草稿はJSONバックアップを利用してください。
- 共有フォーム・回答・票はサーバーのSQLiteへ保存し、**最大30日**の期限があります。現行Render無料プランでは **SQLiteが再起動・再デプロイで消える可能性**があるため、結果は定期的にJSON/CSVで書き出してください。
- 本当に永続化するには `MASTER_DB_PATH` を永続ボリュームへ指定するか、外部の永続データベースを接続する必要があります。**現時点では未設定で、自動的に永続化されたわけではありません**。
- 自動テスト：`python live/test_milli.py`、および既存のお絵描きモードの各テスト。

### 対応する形式

- Tier表：最大15お題、5候補の順位と各候補の画像

- 恋愛究極の２択：最大30問、2択、画像付き

**必須設定**：Render の `tier` サービス → **Environment** → `MASTER_PASSWORD` を追加し、他人に知られていない12文字以上の強いパスワードを登録してください。`okayu` をパスワードにはしないでください。設定後は Render で再デプロイします。

管理ページ：`/master`。全10ゲームの公開・非公開切り替え、現在のルーム表示・強制終了、ニックネーム・日時・ゲーム・操作名のログ検索／削除、ラウンドや得点の履歴・削除、全管理データのJSON書き出しができます。画面にはゲームの答え合わせ済みの内容を表示します。公開オフになったゲームは新規選択・開始できず、ソロの一時共有APIでも取得できません。すでに開始中のルームはそのまま継続します。

**安全性・プライバシー**：ユーザーが入力する `okayu` だけでは管理できません。操作にはサーバー側パスワード認証によるHttpOnlyクッキーが必要で、管理APIは同一サイトからの操作以外を拒否します。参加者には操作ログを記録する旨がサイトの参加画面で通知されます。操作ログはニックネーム・時刻・ルーム・ゲーム・操作種別と設定ゲーム名のみ記録し、個別の秘密の回答・発言本文・IP・セッションIDを操作ログに保存しません。対戦履歴には公開済みのラウンド結果・得点を保存します。端末ごとのブラウザ内に保存した未共有データは、管理者も閲覧・削除できません。

**保存の制限**：初期値はSQLiteで、`MASTER_DB_PATH=/tmp/nakami_master.sqlite3` に保存します。Render無料プランではファイルは永続ではなく、サービスの再作成・再デプロイ・再起動などで公開設定も含めて失われる可能性があります。永続保存には外部DBか永続ディスクを導入してください。永続ディスクを使う場合は `MASTER_DB_PATH` をそのマウント下（例：`/var/data/nakami-master.sqlite3`）へ変更できます。記録は操作ログ30日／最大5000件、ゲーム履歴90日です。JSONを書き出してバックアップしてください。ログの取得と削除は管理者だけが可能です。

**注意**：このリポジトリをPublicにしている以上、ブラウザ配信コード自体は誰でも参照できます。非公開はサイト内でゲーム選択・プレイを止める機能であり、作品のソースコードを完全に秘匿する仕組みではありません。
